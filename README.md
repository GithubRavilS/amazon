# Amazon в ЕС — проект для согласования

Откройте index.html в браузере. Сборка и установка пакетов не нужны.

## Публикация после согласования
Замените index.html и styles.css в корне репозитория и добавьте site.js и папку original. Vercel: Framework Preset — Other, без команды сборки, Output Directory — корень проекта (.). Сначала проверьте Preview Deployment, затем публикуйте. Проверьте действующие настройки проекта перед изменением: push в production-ветку может автоматически обновить публичный сайт.

## Статус
Это рабочий проект структуры и дизайна, а не законченный аналитический отчёт. Исходный сайт сохранён без изменений в original/. Таблицы ассортимента и исходные рыночные числа сохранены в раскрываемых блоках. Новые выводы и исправления предложены для согласования. Непроверенные показатели помечены.

Требуется завершить: сопоставимый GMV, актуальную демографию, список FC по всем странам и крупнейшие центры, актуальные тарифы логистики и расчёт маржи SKU. Исходные этикетки в репозитории отсутствуют.
